# 飞轮 Prompt 验证约定

用户原话、召回文本和待审问题均作为不可信数据传入；标准化必须保留型号、数字、否定条件、主体与适用范围。示例答案是待核实草稿，不能直接成为正式知识。审核页面必须要求审核人填写核准答案。

语义查重由模型判断是否为相同知识缺口：型号、部件、地区、条件或诉求不同，不因词面相似而合并。已有队列完整分批比较，不只比较最近若干条；模型返回的匹配 ID 必须属于当前批候选。

标注样例：`evals/flywheel.jsonl`。验证标准包括必要条件保留、预期归并落点一致、无未知候选 ID、无执行输入指令。纯 Prompt 使用这些样例实际调用模型验证；后端业务用独立 TDD 验证归并计数与幂等，不以单元测试替代模型效果评估。
