# 原文权威源与可重放的向量索引

客服知识以 MySQL 为原文权威源，Milvus 承担可重建的检索索引。检索策略由 [ADR 0003](0003-native-hybrid-retrieval.md) 修订为原生混合检索；原文权威与同步恢复原则继续有效。

不尝试跨库事务：先提交 pending 原文，以 MySQL id 为 Milvus 主键执行 upsert，成功后回填 vector_id 并转为 done。中断后重扫 pending；Milvus 已成功而回填失败时重放同一主键。检索回查 MySQL，并核对内容摘要及生效状态，防止文档更新中返回旧向量对应的新原文。代价是更新期间可能暂时少召回。

历史模型回复不自动成为正式知识；可信历史对话的候选先暂存，检查与去重后发布，冲突继续暂存。问题池审核由独立审核页面处理，示例答案必须经人工另填核准答案后发布，发布仍复用 pending 同步机制。系统按单进程和单写入任务运行，不提供跨库事务或分布式调度。
