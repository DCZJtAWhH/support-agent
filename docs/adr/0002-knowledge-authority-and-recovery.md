# 原文权威源与可重放的向量索引

客服知识以 MySQL 为原文权威源，Milvus 仅承担 BGE-M3 dense 语义检索。用户明确指定这三个组件及单路检索，工具的 keyword 与 matches 契约保持不变。

不尝试跨库事务：先提交 pending 原文，以 MySQL id 为 Milvus 主键执行 upsert，成功后回填 vector_id 并转为 done。中断后重扫 pending；Milvus 已成功而回填失败时重放同一主键。检索回查 MySQL，并核对内容摘要及生效状态，防止文档更新中返回旧向量对应的新原文。代价是更新期间可能暂时少召回。

历史模型回复不自动成为正式知识；演示使用明确标注的已审核对话导出，候选先暂存，整体验证和去重后发布，冲突继续暂存。项目是 demo，采用单任务进程与幂等命令，不建设审批界面、分布式调度或在线混合检索。
