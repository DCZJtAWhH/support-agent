# 完整会话与模型投影分离，工具结果归 checkpoint

第七章按用户确定的方案，使用同一会话的滑窗加追加式分段摘要：两个包含端点的消息锚点划层，摘要独立保存，旧段仅作背景而不再合并。LangGraph 的 `messages` 经 `add_messages` 与 checkpoint 保留完整原文，模型投影单独生成；压缩不回写消息。不同会话的事实不互通。

这修订 ADR 0001 中“新工具申请和结果写 messages”的存储决策：本章新工具链仅进 checkpoint，旧工具行仍可审计；工单和退款申请的数据库幂等约束保留。代价是必须持久保存 SQLite checkpoint，不能仅备份 MySQL 来恢复新工具轨迹。模型调用的 system 和工具定义固定，变化的梗概与证据放在当前用户原话之后，避免上游将多个 system 上提合并而破坏前缀缓存。只执行 JSON 任务的问题理解和分类器收到同一滑窗的数据封装，防止误续跑历史工具协议。
