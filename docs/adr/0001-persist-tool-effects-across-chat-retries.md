# 工具副作用跨聊天失败保留，以稳定请求标识恢复

人工工单可能在最终回复生成或发送前已写入，聊天失败时不能丢弃已执行效果。业务写入通过短事务持久保存，失败回答保留为审计但不进入后续完整对话上下文；同轮重试复用调用方生成的 `request_id`，恢复工具检查点，`tickets.request_id` 唯一约束保证同一请求最多一张工单。人工工单不随聊天断流撤销；调用方必须保留请求标识，才能在首次 `meta` 未送达时可靠恢复。

工具轨迹的存储位置由 [ADR 0004](0004-session-context-projections.md) 修订：新工具申请和结果保存在 SQLite checkpoint，历史 messages 工具行仍可审计。业务幂等与失败效果保留原则继续有效。
