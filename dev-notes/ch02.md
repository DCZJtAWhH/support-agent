### 依赖与 Context7 查证

- 当前实际版本：FastAPI 0.165.0、langchain-core 1.8.3、langchain-openai 1.8.3、Pydantic 2.14.3、OpenAI SDK 3.55.1。尚未引入 SQLAlchemy 或 MySQL 驱动。
- 已通过 Context7 查询 LangChain Python、SQLAlchemy 2.0.55 和 FastAPI 官方文档。
- LangChain：`@tool(args_schema=...)` 支持 Pydantic 参数定义；`AIMessage.tool_calls` 表示模型调用申请；回灌的 `ToolMessage.tool_call_id` 必须匹配调用申请 ID。最终使用未绑定工具的模型生成回答，可落实本章不进行第二次工具决策的要求。
- LangChain：部分供应商支持 `parallel_tool_calls=False`，但不能直接假设现有兼容服务支持该参数，需结合实际服务验证。
- SQLAlchemy：Session/AsyncSession 都是有状态事务对象；不能在并发任务间共享，异步方案需每任务独立 AsyncSession。SQLAlchemy 官方提供 MySQL 的 aiomysql 异步方言。
- FastAPI：0.118.0 起，yield 依赖的清理发生在流式响应结束后；不能依赖请求结束前关闭数据库会话的旧行为。数据库事务生命周期应明确管理，避免模型流式生成期间长期占用事务。
