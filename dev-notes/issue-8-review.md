   校验 JSON Schema，执行复用同一份 Schema。公开工具执行与持久审计回归已复现失败并通过修复。

## Spec

1. **P2，已修复**：公开知识发布能力无条件更新来源，同一发布标识的不同问题或答案会覆盖原文，
   违反“相同标识搭配不同业务输入明确返回冲突”。现在知识模块在短事务中保存首次核准内容，
   依靠既有唯一来源键和原内容摘要核对重试；原文 pending 和索引 done 均不可被不同输入覆盖。
