评估口径与适用范围

Recall 与 MRR 只统计有 ground-truth 的题目。Faithfulness 由独立模型调用把回答拆成原子事实，再计算被召回原文支持的比例；拒答没有事实时为 N/A，不算满分。

当前标注集用于开发回归，阈值也参考过开发反馈，并非独立留出集。模型评委需要人工抽查。上传新内容后，重新评估会使用当前知识库，但不会自动为新知识生成标注题。

重新评估会运行全部已有标注题并调用真实模型，通常需要数分钟；关闭此页面后任务仍在后台运行。评估期间请保持知识库和标注集不变。
